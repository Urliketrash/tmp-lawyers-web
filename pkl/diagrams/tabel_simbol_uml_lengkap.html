Tabel 2. 2 Simbol Use Case Diagram

Simbol Nama Deskripsi
Actor Menspesifikasikan himpunan peran yang pengguna mainkan ketika berinteraksi dengan sistem.
Use Case Deskripsi dan urutan aksi-aksi yang ditampilkan sistem yang menghasilkan hasil terukur bagi aktor.
Association Menghubungkan antara aktor dengan use case.
Extend Menspesifikasikan bahwa use case target memperluas perilaku dari use case sumber.
Include Menspesifikasikan bahwa use case sumber secara eksplisit menyertakan perilaku use case lain.
System Boundary Menspesifikasikan batas sistem yang menampilkan use case di dalamnya.

Tabel 2. 3 Simbol Activity Diagram

Simbol Nama Deskripsi
Initial Node Status awal yang menandakan dimulainya suatu aktivitas.
Activity Memperlihatkan aktivitas atau aksi yang dilakukan dalam proses.
Decision Pilihan untuk mengambil keputusan berdasarkan kondisi tertentu.
Fork/Join Node Percabangan atau penggabungan aliran aktivitas.
Activity Final Node Status akhir yang menandakan berakhirnya suatu aktivitas.

Tabel 2. 4 Simbol Class Diagram

Simbol Nama Deskripsi
Class Blok pembangun pada pemrograman berorientasi objek yang terdiri dari nama, atribut, dan method.
Association Hubungan umum antara dua class.
Aggregation Relasi mempunyai dimana class anak dapat berdiri sendiri.
Composition Relasi bagian dari dimana class anak tidak dapat berdiri sendiri.
Generalization Relasi inheritance dimana class anak mewarisi perilaku class induk.
Dependency Relasi ketergantungan antar class.

Tabel 2. 5 Simbol Sequence Diagram

Simbol Nama Deskripsi
Actor Menunjukkan pengguna atau aktor yang berinteraksi dengan sistem secara eksternal.
Lifeline / Object Menunjukkan objek atau kelas yang berpartisipasi dalam interaksi sequence.
Activation Bar Menunjukkan periode waktu di mana suatu objek sedang aktif melakukan operasi.
Message Menunjukkan pengiriman pesan atau pemanggilan metode dari satu objek ke objek lain.
Return Message Menunjukkan nilai pengembalian atau hasil dari pesan yang sebelumnya dipanggil.
