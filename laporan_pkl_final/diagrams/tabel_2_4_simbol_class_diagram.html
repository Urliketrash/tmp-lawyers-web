Tabel 2.4 Simbol Class Diagram

Daftar simbol dan notasi yang digunakan dalam perancangan Class Diagram
Simbol Nama Deskripsi
Class Blok pembangun pada pemrograman berorientasi objek yang terdiri dari nama, atribut, dan method.
Association Hubungan umum antara dua class.
Aggregation Relasi mempunyai dimana class anak dapat berdiri sendiri.
Composition Relasi bagian dari dimana class anak tidak dapat berdiri sendiri.
Generalization Relasi inheritance dimana class anak mewarisi perilaku class induk.
Dependency Relasi ketergantungan antar class.
