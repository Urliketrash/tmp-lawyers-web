Tabel 5. 1 Struktur Koleksi News

No Nama Field Tipe Data Keterangan
1 id String Kunci dokumen unik (auto-generated)
2 title String Judul artikel berita
3 date String Tanggal publikasi berita
4 category String Kategori artikel (misal: Pidana, Perdata)
5 summary String Deskripsi singkat berita di halaman utama
6 content String Isi artikel berita lengkap dalam format HTML
7 imageUrl String Tautan path gambar berita di Firebase Storage
8 author String Nama penulis berita
Tips: Gunakan Win+Shift+S untuk screenshot tabel B&W ini dan paste langsung ke Microsoft Word.

Tabel 5. 2 Struktur Koleksi Lawyers

No Nama Field Tipe Data Keterangan
1 id String Identifier unik profil pengacara
2 name String Nama lengkap pengacara beserta gelar akademis
3 role String Jabatan pengacara di firma (Founding Partner, dll)
4 image String Tautan berkas foto profil pengacara
5 shortDesc String Deskripsi singkat pengacara
6 biography String Riwayat hidup dan biografi karir hukum lengkap
7 email String Email profesional pengacara
8 skills Array Daftar bidang keahlian hukum yang dikuasai
Tips: Gunakan Win+Shift+S untuk screenshot tabel B&W ini dan paste langsung ke Microsoft Word.

Tabel 5. 3 Struktur Data Users (Firebase Authentication)

No Nama Field Tipe Data Keterangan
1 uid String User ID unik admin (auto-generated)
2 email String Alamat email terdaftar admin
3 password String Sandi keamanan terenkripsi (diuji internal)
Tips: Gunakan Win+Shift+S untuk screenshot tabel B&W ini dan paste langsung ke Microsoft Word.
